# 🛠 Projects

## 🌱 IDIYANALE NPK Monitoring System
My first project was a group project under the guidance of Kodic Guzman, where we developed a system using C++ and the Arduino Uno. 

This project was successfully presented during our school exhibit, allowing us to showcase our programming, hardware integration, and teamwork skills.
The NPK Sensor Project is a smart agricultural system designed to measure the levels of nitrogen (N), phosphorus (P), and potassium (K) present in the soil. These essential nutrients play a vital role in plant growth by supporting leaf development, root strength, and overall crop productivity.

The system utilizes an NPK sensor connected to an Arduino Uno to collect and display real-time soil data. By analyzing the nutrient levels, farmers and gardeners can determine the appropriate amount of fertilizer needed for the soil, helping reduce resource waste while improving crop quality and yield.

This project highlights the application of technology in modern agriculture by providing a faster, more accurate, and efficient method of soil monitoring and nutrient management.The project aims to help farmers and gardeners monitor soil conditions more efficiently and make better decisions for crop management.


### 🔧 Features

- Real-time soil nutrient monitoring
- LCD display output
- Arduino-based system
- Sensor data processing using C++
